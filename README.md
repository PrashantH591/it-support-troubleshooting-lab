# 🖥️ IT Support Troubleshooting Lab

A practical IT support portfolio project documenting troubleshooting techniques for Windows systems, networking, hardware and common end-user issues.

The objective is to demonstrate a structured approach to diagnosing, resolving and documenting IT incidents.

---

## 🎯 Objectives

- Diagnose common Windows issues
- Troubleshoot network connectivity
- Investigate DNS and DHCP problems
- Perform basic hardware troubleshooting
- Use command-line diagnostic tools
- Document incidents and resolutions
- Develop repeatable IT support procedures
- Practice escalation and incident management

## 🔍 Troubleshooting Methodology

I follow a structured troubleshooting process:

1. Identify the problem
2. Gather information
3. Reproduce the issue where possible
4. Identify possible causes
5. Test the most likely cause
6. Apply the appropriate fix
7. Verify the solution
8. Document the incident
9. Escalate when required
